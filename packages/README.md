# Pacotes

## Versão atual Linux: 3.4.1

Baixe os instaladores pela [GitHub Release v3.4.1](https://github.com/airtonbp19edu/Print-and-View-PDF/releases/tag/v3.4.1):

- [print-view-pdf_3.4.1_all.deb](https://github.com/airtonbp19edu/Print-and-View-PDF/releases/download/v3.4.1/print-view-pdf_3.4.1_all.deb).
- [PrintViewPDF-3.4.1-x86_64.flatpak](https://github.com/airtonbp19edu/Print-and-View-PDF/releases/download/v3.4.1/PrintViewPDF-3.4.1-x86_64.flatpak).
- [SHA256SUMS](https://github.com/airtonbp19edu/Print-and-View-PDF/releases/download/v3.4.1/SHA256SUMS), com somente os dois arquivos desta versão.

Uma cópia do manifesto específico está em [SHA256SUMS-3.4.1](SHA256SUMS-3.4.1).
Novos instaladores são distribuídos em Releases para evitar acrescentar
binários grandes a cada revisão do código.

## Histórico preservado

Os seis arquivos antigos já rastreados neste diretório permanecem disponíveis.
O instalador Windows é [3.4.0](PrintViewPDF-3.4.0-Setup-x64.exe) e não contém
as preferências novas. Os pacotes ~test e os pacotes Linux 3.4.0 são históricos.

[SHA256SUMS](SHA256SUMS) é o inventário conjunto dos seis arquivos antigos e dos
dois novos arquivos baixados da release. Para conferir somente a versão atual,
use o SHA256SUMS distribuído junto aos assets da release.
